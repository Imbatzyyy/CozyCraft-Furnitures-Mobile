# CozyCraft Mobile 1.0.48

Home Circle has a warm ivory layout with readable points, available rewards, tier progress, and recent activity. Body copy follows all four text-size preferences; headings scale more conservatively and controls wrap on narrow screens. Reward exchanges require confirmation and prevent repeated requests while processing. Expired rewards move to history even when a cached row still says available.

The entry tier is now Cozy Nest throughout mobile membership, account, and chatbot displays. A generated database display-name column maps stable tier keys to customer-facing names, preserving older clients and all existing points, spending, and reward rules. No website source was changed.

Realtime loyalty refreshes now read the account instead of invoking the writing calculation RPC, avoiding a feedback loop. Bursts are coalesced. Initial account calculation and server-authorized redemption remain intact. Only benefits supported by the database rules are described.

Validation: 195 frontend tests passed, including confirmation, duplicate-tap prevention, failed exchanges, insufficient balances, expired rewards, and owner-filtered read-only realtime loading. A local fixture passed 32 Chromium/WebKit combinations across four viewport sizes and all four text sizes, including landscape, with no horizontal overflow or clipped button content. These browser checks use simulated reward responses, not real customer points. The production tier migration was applied and read back with points and spending totals unchanged. TypeScript, storefront production build, Android debug APK, and iOS Simulator build passed. Physical-device redemption and multi-device realtime delivery remain release smoke checks.
