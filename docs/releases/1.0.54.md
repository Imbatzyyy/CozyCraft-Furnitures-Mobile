# CozyCraft Mobile 1.0.54

A bottom-left Back control appears after scrolling down long detail screens. It delegates to each screen's existing back action for products, profile editing, categories, notifications, Home Circle, search, Care chat, order details, account sheets, comparisons, and information/legal pages. Root tabs and checkout do not receive a duplicate back control.

The control hides at the top, while typing, when an unsupported nested dialog is active, or when the original back action is disabled. It respects the bottom safe area and reserves space above the navigation bar, chat composer, and profile save action. Scroll updates are scheduled once per animation frame and do not make network requests.

Validation includes TypeScript, the existing test suite, and Chromium/WebKit checks at four viewport sizes with Extra Large text for the scroll threshold, original callback, disabled state, nested dialog, input focus, and viewport bounds. Physical-device keyboard testing remains a device smoke check.

Android is a direct-install debug APK. iOS source and assets are available for Xcode installation; this is not an App Store or TestFlight release.
