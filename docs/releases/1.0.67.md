# CozyCraft Mobile 1.0.67

Fixes the new Google-account welcome sequence. A single coordinator orders account setup, the optional tutorial, then the existing issued welcome voucher with the voucher mascot. Finish and Skip both hand off to the voucher without acknowledging it. Existing completed tutorials do not need to replay to access an unseen voucher.

The tour no longer depends entirely on an additional metadata request: verified first-time onboarding state provides a fallback when that lookup fails. Refreshing eligibility does not reset an in-progress tour. Voucher acknowledgement now keeps errors visible instead of optimistically hiding the popup on failure.

Reward issuance, amounts, eligibility and previously acknowledged voucher records are unchanged; no duplicate vouchers or retroactive reward grants. No database schema change.

Validation: TypeScript, 232 storefront tests, native-shell tests, combined Google setup → tutorial Finish/Skip → sticker voucher → interactive storefront checks in Chromium and WebKit at 320x568 with extra-large text, Android build and iOS simulator build. These are controlled integration fixtures, not a real Google-provider signup or a live voucher grant.

Android direct-install debug APK: 1.0.67/versionCode 68. iOS Xcode source: 1.0.67/build 55. Not an App Store or TestFlight release. Website, checkout and search unchanged.
