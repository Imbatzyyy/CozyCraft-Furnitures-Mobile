# CozyCraft Mobile 1.0.80 — Show confirmation immediately after Continue payment

Based on 1.0.79 (`cad7207`). Android versionCode **81**; iOS version
**1.0.80**, build **68**.

## Fix

Resuming payment from My Orders left the Account component's body-level Orders
and order-detail portals mounted above the newly opened Order Confirmed screen.
The successful return had arrived, but the customer had to close Orders manually
to see the confirmation behind it.

- Account and its portals now unmount in the same render that opens confirmation.
  This handles continuation from both the Orders list and an individual order.
- Successful return and verified paid-payment recovery clear queued account/order
  navigation so a stale request cannot restore a sheet over the confirmation.
- A late native browser-dismiss event is ignored once the pending payment has
  already been consumed; it cannot reopen Orders after success.
- Existing confirmation design, animation, View order details and Continue
  browsing actions are retained. Cancelled/unfinished returns still show Orders
  and preserve the original payment deadline.
- No backend, database, payment-settlement or payment-routing changes. No new
  polling, timers or dependencies. The 1.0.79 app-return deployment remains live.

## Install

The GitHub APK is **debug-signed for testing**, not a Play Store release. For iOS,
build/run `ios/App/App.xcodeproj` on the phone with Xcode. Publishing the source
does not update an already-installed iPhone app; no physical installation or
App Store/TestFlight submission was performed.
