# CozyCraft Mobile 1.0.52

CozyCraft Care has a quieter conversation-first layout: a left back arrow, compact header, short welcome and two suggested questions. The repeated greeting and account banner are removed from the visible welcome screen. Starter prompts disappear after sending a message. Message text follows the reading-size preference while decorative elements scale conservatively.

The header reflects offline and account-connecting states. Existing account answers, product suggestions, response formatting, feedback and contextual navigation remain available. Natural questions about seeing, finding or accessing support now produce the direct Care & Support action.

Browser fixtures check sending, an order answer, reset, support guidance and navigation, offline status and back across phone, tablet and landscape sizes in Chromium and WebKit. These checks do not prove every live AI response or physical-device keyboard behavior.

Android is distributed as a direct-install debug APK. iOS source and assets are prepared for Xcode installation; this is not an App Store or TestFlight release. No website or database-schema changes are included.
