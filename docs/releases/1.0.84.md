# CozyCraft Mobile 1.0.84 — More natural CozyCraft Care

October 16, 2026. Android versionCode **85**; iOS build **72**.

## What changed

- Fix the greeting being displayed as WHERE TO GO: the formatter previously
  interpreted "choose" anywhere in a sentence as a navigation instruction,
  including "I can help you choose furniture". It now recognizes actual
  imperative directions instead of verbs mentioned in conversational prose.
- Keep ordinary numbered product lists as text, not navigation steps. Only
  derive destination buttons from actual directions. Existing support-page
  directions and their in-app button still work.
- The canonical backend now answers common English/Filipino greetings,
  assistant identity/capabilities, CozyCraft basics, bag/wishlist definitions,
  thanks and goodbyes directly, without database reads or paid AI generation.
- A greeting followed by a real order, payment or product question still goes
  through the relevant lookup and safety checks. Dynamic facts are not added
  to the static conversation shortcuts.
- Updated provider instructions prioritize answering the customer's question.
  Steps are used for procedures/navigation/troubleshooting, not every answer.
  The general fallback asks about the concern instead of demanding a page name.

## Deployment and boundaries

Shared `cozycraft-assistant` function **44** is active. Website deployment
`6ad13f1b5b7f6f629331ca07` is live at https://www.cozycraftfurnitures.com.
The backend changes help existing installations, but the formatting fix
requires installing this rebuilt native app.

No database schema, customer records, payment processing or notification
credentials were changed. No physical-phone installation, paid transaction,
App Store/TestFlight or Play Store submission was performed. The APK is
debug-signed for direct testing; physical iPhone installation remains with the
user through Xcode. Provider answers can vary; fixture tests and simulator
launch do not prove every question or physical-device experience.

The prior release's development-only dependency findings and missing APNs
credentials remain outside this targeted chat fix. Runtime audits remain clean.
