# CozyCraft Mobile 1.0.55

- Added View order details to the order confirmation screen, opening the exact confirmed order. Home and browsing actions remain available.
- Fixed order details being hidden when the orders list has not finished refreshing.
- Added responsive First name and Last name inputs to checkout and account address editors. Values save together in the existing recipient_name database field, preserving website compatibility. Legacy full names are initially split at the first space and remain editable.

Validation: 206 tests, TypeScript, Android debug build, iOS simulator build, and Chromium/WebKit recipient-field layouts at 320, 390, and 768 pixels with Extra Large text. No production customer orders or addresses were modified for testing. Physical-device and authenticated production readback checks remain separate.

Android is a direct-install debug APK. iOS source and assets are ready for Xcode installation. This is not an App Store, TestFlight, or Google Play publication. The customer website was not changed.
