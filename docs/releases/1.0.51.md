# CozyCraft Mobile 1.0.51

Search discovery shortcuts now use up to four distinct, nonempty product names from the loaded catalog instead of hard-coded phrases. Tapping a shortcut fills the existing search query. Matching, ranking, filtering, synonyms, and suggestion logic are unchanged.

The section is labeled Discover pieces and uses readable wrapping labels, consistent SVG arrows, and a single-column layout on narrow screens. No new database requests or schema changes are introduced.

Validation before release: 201 automated tests and 32 browser/layout shortcut checks passed. Android is a direct-install debug APK; iOS source and assets are available for Xcode installation, not App Store or TestFlight distribution. The website is unchanged.
