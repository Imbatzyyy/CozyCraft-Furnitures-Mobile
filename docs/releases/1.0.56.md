# CozyCraft Mobile 1.0.56

Fixed the Orders page heading being covered by the storefront header. Account screens now render outside the underlying page layer, with restored top safe-area spacing, readable wrapping, and a reachable close button. The chatbot remains hidden on account sheets. Order navigation and the shared account-screen behavior are preserved.

Validation: 206 tests, TypeScript, app build, and Chromium/WebKit layout and order-navigation checks at 320, 390, and 768 pixels with Extra Large text. Actual iPhone safe-area behavior remains a physical-device check.

Android is a direct-install debug APK. iOS source and assets are available for Xcode installation, not TestFlight or App Store distribution. The customer website was not changed.
