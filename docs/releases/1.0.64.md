# CozyCraft Mobile 1.0.64

Introduces the supplied CozyCraft companion artwork in selected existing UI spaces: Care introduction, empty wishlist/cart, welcome voucher, published-review success, empty notifications, and confirmed Home Circle reward/tier celebrations.

Short entrance and optional tap greeting; no sound, blocking popup or continuous animation. Reduced motion is respected. Home Circle does not celebrate on initial load and allows dismissal. Artwork failures do not block shopping. Existing artwork is preserved, including sticker borders.

Validation: 223 storefront tests, native-shell tests, TypeScript, native builds, and responsive regression checks. Prior mascot-specific Chromium/WebKit checks verified image loading, tap animation and reduced-motion behavior. Physical iPhone/Android interaction and performance remain device checks, not guaranteed by browser testing.

The startup logo, sofa-loading sequence, checkout/security rules, search system, website and database are unchanged. Android download is a direct-install debug APK. iPhone source is ready for Xcode installation; this is not a TestFlight/App Store release.
