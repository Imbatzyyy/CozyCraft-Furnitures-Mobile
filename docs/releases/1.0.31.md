# CozyCraft Mobile 1.0.31

- Adds a bundled SVG sofa loader for app preparation, catalog refresh, pull-to-refresh, order submission, and payment confirmation. The cushions gently settle while the request is in progress.
- Adds short fades for tab changes, checkout steps, product screens, account sheets, and other customer pages. Existing state stays mounted when changing tabs; motion does not delay navigation or network work.
- Uses only opacity and small vector transforms for the new animations. No animation library, GIF, remote animation asset, or animation network request is added.
- Uses shorter transitions and a still sofa when available device signals indicate limited memory, four or fewer logical processors, or data-saving mode. Devices without those signals receive the lightweight default.
- Honors reduced-motion settings and pauses CSS animations when the document is hidden.
- Includes a browser motion audit covering narrow and tablet widths, reduced motion, economy mode, and removal of page transforms after entry.

The Android download is a debug APK for direct installation. iOS is prepared for an Xcode build; this release does not publish to the App Store or TestFlight. Physical low-end device frame-rate testing remains a device validation step.
