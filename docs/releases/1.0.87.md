# CozyCraft Mobile 1.0.87 — Account layout and Text size shortcut

October 21, 2026. Android versionCode **88**; iOS build **75**.

## What changed

- Center **Privacy** on its own row below **Company History** and **Terms**.
  Keep the same two-column layout and touch-sized buttons on phones and tablets.
- Add **Text size** to the side menu under **Your CozyCraft**. It opens the
  existing reading-comfort panel directly, including for guests. The Account
  button and CozyCraft Care's Text size destination open the same panel.
- Apply Standard, Comfortable, Large, and Extra large immediately and keep the
  choice on the device. Text settings share the Account layer state, so Done,
  Close, Escape, backdrop dismissal, and native Back cannot leave a stale panel.
- Include the previously local original-app fixes: vibration-free routine tab
  navigation, safe native Back dismissal of the menu/information pages, and the
  display name **Cozy Craft Furnitures** on Android and iOS. Keep the side menu
  and the approved app Developers roster with **Sammuel Guill Concepcion**.
- Update the Angular 20.3 framework packages from 20.3.33 to the compatible
  20.3.34 security patch. Both production dependency audits report no known
  vulnerabilities. See the [Angular security advisory](https://github.com/advisories/GHSA-jfgx-762w-99vr).
