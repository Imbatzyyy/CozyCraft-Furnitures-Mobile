# CozyCraft Mobile 1.0.35

- Consolidates the root splash, account-security check, lazy storefront route, and first catalog hydration into one shared CozyCraft sofa loading surface.
- Removes the fixed launch delay so signed-in customers reach the app as soon as the session is ready instead of waiting through a second branded loading scene.
- Keeps later refresh, payment, checkout, photo, and verification indicators scoped to the action the customer started; an already interactive page does not become a full-screen loader.
- Prevents the initial empty-catalog state from rendering a second inline loader while cached products are unavailable.

Validation: storefront typecheck, 182 storefront tests, production storefront build, root lint, and native metadata/version checks. Native simulator/device builds remain part of the release preparation run.
