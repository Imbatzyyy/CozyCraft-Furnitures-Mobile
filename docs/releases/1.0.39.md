# CozyCraft Mobile 1.0.39

The loading sofa draws its outline, raises its backrest, and lands its cushions in a five-second loop. The branded splash now leads into a dedicated five-second sofa presentation before the normal destination and any remaining data/security preparation. This also runs for signed-out customers. Ordinary refreshes do not receive the launch delay. Economy mode retains outline tracing and backrest motion; Reduce Motion uses the completed static sofa.
