# CozyCraft Mobile 1.0.50

Home Circle's balance card now has a subtle circular background, a readable balance label, an outlined tier badge, and a separate progress area. Static CSS decoration needs no additional image downloads or animation.

Rewards, point exchanges, tier progression, and recent activity now have distinct section separators and warm-tinted heading panels. Flexible headings and controls continue to follow all four text-size settings. Recent Activity pagination and existing reward/database logic are unchanged.

Android is distributed as a direct-install debug APK. Updated iOS source and assets are available for Xcode installation, not TestFlight or App Store distribution. The customer website and database schema are unchanged.
