# CozyCraft Mobile 1.0.28

Realtime cart stock visibility.

- Shows the available stock for every product currently in the customer’s bag.
- Disables the quantity increase control at the live stock limit and clearly labels the item as maximum available.
- Prevents add-to-cart and saved-piece actions from silently exceeding available stock.
- Detects when live stock falls below a quantity already in the bag, explains what to change, and prevents checkout until it is corrected.
- Keeps stock updates low-egress by reusing the existing coalesced product realtime channel and refreshing only changed product IDs.
- Applies the responsive stock layout to iPhone and Android builds without changing the customer website.

Validation: storefront type check, 175 storefront tests, production build, root lint, and 160-layout responsive QA sweeps for both iOS and Android passed without horizontal overflow or runtime errors. Native web assets are regenerated from this release.
