# CozyCraft Mobile 1.0.60

- Review photos now sit beside one another in a left-aligned thumbnail row, wrapping on narrow screens.
- Added a dual-handle price range for Living Room, Bedroom, and Dining categories. Both minimum and maximum filter the results, handles cannot cross, keyboard adjustment is supported, and Reset restores the full range. Existing search behavior is unchanged.
- Added the existing CozyCraft logo to the top of newly requested invoice emails. The invoice template endpoint is deployed; existing inbox messages do not change. The versioned email retry key avoids conflicts with the previous template.

The email includes the logo as an inline attachment, avoiding the hosted image's cross-site restrictions. The rendered invoice preview was checked; a new real-inbox delivery was not sent during testing.

Validation: 214 app tests; invoice backend tests; 24 Chromium/WebKit responsive cases covering four text sizes, both draggable handles, keyboard control, Reset, and adjacent photos; Android and iOS simulator builds. Actual device gestures and Gmail/Apple Mail rendering remain device/client checks.

Android is a direct-install debug APK. iPhone source/assets are ready for Xcode installation, not App Store or TestFlight distribution. No customer website code or database schema was changed.
