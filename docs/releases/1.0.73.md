# CozyCraft Mobile 1.0.73 — Manual signup welcome voucher

Fixes the missing welcome voucher after manual account signup and the tutorial.

## Root cause

Manual accounts were excluded at three layers: the client returned an empty onboarding status without a request, the storefront only rendered voucher status for Google identities, and only Google username completion issued the database-backed reward. The previous manual-signup audit stopped after the tutorial instead of asserting the reward handoff.

## Changes

- Both signup methods now request the authenticated customer onboarding status. Google name/username setup is preserved; email customers are not asked to repeat it.
- A new database RPC issues the existing welcome reward for verified manual customer accounts created in the last 30 days with no previous orders. It uses the same profile lock, unique one-welcome-reward index, reward storage, and acknowledgement state as Google signup.
- The reward remains **PHP 500 off**, **PHP 5,000 minimum merchandise subtotal**, expiring **30 days after issuance**. Tutorial metadata cannot grant eligibility.
- Finish and Skip both hand off to the existing premium voucher popup with the provided mascot sticker. The voucher is already stored in the database, not a display-only offer.
- Eligible accounts that already completed the tutorial can recover their missed voucher on the next launch of this version. They do not need a new account or to repeat the tutorial.
- A post-tutorial reward check recovers failed initial requests; a visible retry is offered if the request still fails. A late response cannot reopen a voucher dismissed during that request.
- Acknowledgement hides the popup without consuming the reward. Retries, relaunches and tutorial replays do not duplicate, renew, or replace used/expired rewards.
