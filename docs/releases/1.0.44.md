# CozyCraft Mobile 1.0.44

The launch handoff now prepares the customer home route behind the branded sofa sequence. Auth/security checks, lazy route loading, and catalog preparation can begin while the sofa is drawing, so the finished transition reveals an already prepared home instead of starting another loading screen.

The sofa completes one five-second drawing cycle, holds its finished pose for one second, and then uses the 800ms sofa-matched exit transition. The warmed security state and handoff marker are reused when the home route takes over. If security needs an authenticator challenge or reports an error, the launch overlay releases so the customer can reach that recovery screen instead of being left behind the animation.
