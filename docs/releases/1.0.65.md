# CozyCraft Mobile 1.0.65

Guided account creation with the five supplied CozyCraft mascot poses: name, username, email, password security, and email confirmation. Short directional entrances, optional tap greetings, reduced-motion support, clear progress and Back navigation. Smaller viewports remain scrollable; no mandatory animation delays or sound.

Google onboarding now confirms editable first and last names before the existing unique-username step. Existing accounts continue to use the backend onboarding status; welcome rewards remain database-issued, not UI-generated.

Account creation retains Supabase signup, email confirmation links, current account settings, and profile creation. Names and username are sent in the signup metadata; the existing trigger writes full_name and username to profiles. Google name updates are restricted to the signed-in profile and checked for successful database response before onboarding completion. Passwords are not persisted to browser storage and are cleared when the verification screen opens. Network failures are recoverable; duplicate signup submissions are guarded.

Verification: 226 storefront tests, 13 native-shell tests, TypeScript, eight Chromium/WebKit signup-and-resend fixture scenarios (320px, 390px, landscape and tablet; larger text and reduced motion), and Google Back-navigation checks in both engines. Live database account settings and signup-trigger mapping were checked; a signup profile assertion passed inside a rolled-back transaction, leaving no test account. No database schema changes.

Android is a direct-install debug APK, versionCode 66. iOS version 1.0.65/build 53 is provided as Xcode source, not a TestFlight/App Store publication. Browser fixtures and simulator compilation do not verify real email inbox delivery, live Google-provider authorization, or physical-device keyboard and performance behavior.

The website, checkout, search and furniture catalog systems are unchanged.
