# CozyCraft Mobile 1.0.34

- Keeps cart rows in the customer’s current visual order when selecting or unselecting an item.
- Preserves that order across realtime cart updates, pull-to-refresh, reconnect hydration, payment reconciliation, and account refreshes.
- Appends genuinely new cart products after existing rows so an update cannot make an item jump below another item.
- Keeps selection state, stock messaging, totals, and checkout eligibility synchronized with the refreshed line data.

Validation: storefront typecheck, 181 storefront tests, production storefront build, root lint, native asset preparation, Android debug build, and iOS simulator/device SDK builds.
