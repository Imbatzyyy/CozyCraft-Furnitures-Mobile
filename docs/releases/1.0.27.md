# CozyCraft Mobile 1.0.27

Responsive bag quantity controls.

- Kept each bag item’s price and quantity control in the same responsive purchase row.
- Replaced uncontrolled spacing with a bounded gap that adapts to the available width.
- Allows the quantity control to wrap cleanly on narrow phones and preserves comfortable touch targets.
- Applies the same layout to iPhone and Android storefront builds without changing the customer website.

Validation: storefront type check, 171 storefront tests, production build, root lint, and 160-layout responsive QA sweeps for both iOS and Android passed without horizontal overflow or runtime errors. Native web assets are regenerated from this release.
