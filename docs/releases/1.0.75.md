# CozyCraft Mobile 1.0.75 — A considered side menu

An app-only navigation drawer and dedicated About the App / Developers pages
for Laboratory Activity 4.2. The customer website and shared database are unchanged.

## Included

- Hamburger entry beside the logo; the existing logo shortcut, search,
  notifications, profile controls, and bottom navigation remain available.
- Home, shopping, wishlist, bag, orders, Home Circle, account and Care shortcuts
  connected to existing app handlers, plus About the App and Developers.
- Active destination highlighting, matching ivory/sage styling, safe-area
  spacing, responsive layouts, and support for the app's larger text preference.
- Short drawer transitions, guarded rapid taps, reduced-motion/economy behavior,
  keyboard focus containment/return, background isolation, and native Back support.
- Information pages preserve the storefront underneath and their reading
  position when the drawer is dismissed. No extra authentication/database calls
  are introduced by these pages.
- App-only developer roster: Prince Balane, Joylyn Campuso, **Sammuel Guill
  Concepcion**, Angela Faith Suba and Hydee Mae Sumalinog, with all five approved
  school email addresses. Sammuel's supplied portrait replaces Jacob in the
  app roster; the other four portraits and roles are retained.
- Bundled, lazily decoded team portraits. A lab requirement map, source guide,
  screenshots, and remaining submission checklist are in
  `docs/SIDE-MENU-LAB-4.2.md`.

## Verification

- **292 frontend tests in 57 files**, including seven new navigation tests.
- **18 native-shell tests** and **8 Xcode-toolchain tests**.
- Frontend typecheck, native-shell lint, React and Angular production builds.
- **20 full-app menu combinations against the compiled production frontend**:
  Chrome/WebKit, 320/390/768/844/1440-pixel widths, portrait/landscape, comfortable
  and extra-large text. Checked all destinations, active states, horizontal
  overflow, contacts/portrait loading, focus containment, native Back, underlying
  dock isolation, and preservation of the information page's scroll position.
  Includes reduced-motion and four-times CPU-throttled Chrome smoke tests.
- **14 existing full-app Google/manual onboarding journeys** passed in Chrome
  and WebKit, including tutorial completion/skip, welcome vouchers, retry,
  dismissal and reload. Backend HTTP/WebSocket requests were intercepted; no
  actual accounts, emails, payments or vouchers were created.
- Android debug APK and **Xcode 27 iOS simulator** builds passed. All **158 web
  files** match byte-for-byte in both native packages and the production build.
- Android signature verified; its certificate matches the previous local test APK.
