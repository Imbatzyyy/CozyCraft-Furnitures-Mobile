# CozyCraft Mobile 1.0.85 — Care navigation and Account information

October 16, 2026. Android versionCode **86**; iOS build **73**.

## What changed

- Suppress the global floating Back control whenever CozyCraft Care is open,
  including long conversations, feedback, and scrolled background pages.
  The header now has one clearly labelled **Close CozyCraft Care** X control.
  Existing native Back and edge-swipe dismissal remain available.
- Add **Developers** and **Company History** beside **Contact Us** in the Account
  information links. These open the existing in-app information pages without
  unmounting the storefront. The information links use responsive touch-sized
  tiles; the nearby notification button wraps cleanly on narrow screens.
- Align chatbot guidance with **30 mobile destinations** rather than website
  footer links and account tabs. Cover the menu, room collections, search,
  comparison, profile/security/preferences, rewards, and account-access screens.
  Order-specific guidance explains invoice requests, payment continuation,
  reviews, cancellation, and returns without performing those actions.
- Use the current mobile Developers roster, including **Sammuel Guill
  Concepcion**, separately from historical website founding information.
- Share a reviewed navigation reference with the canonical Supabase backend.
  `node scripts/sync-assistant-pages.mjs <website-checkout>` verifies parity;
  menu-coverage and exact-page-name tests guard against missing destinations.
  Simple navigation remains local, and the backend page overview needs no
  database or paid AI request. General greetings remain conversational.
