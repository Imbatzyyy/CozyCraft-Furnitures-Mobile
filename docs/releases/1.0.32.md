# CozyCraft Mobile 1.0.32

- Restores the CozyCraft Care launcher to its original floating position in the lower-right corner above the navigation dock.
- Replaces the header chat control with one compact circular button inspired by the supplied Care reference: an outlined chat icon, a small green availability dot, and a restrained liquid-glass surface.
- Adds safe-area spacing for iPhone and Android edge-to-edge layouts, a 56px touch target, focus-visible styling, and a small press/hover response.
- Hides the launcher while the full Care conversation is open so it cannot sit above the composer or intercept chat touches.
- Uses existing Material Symbols and CSS only; no remote icons, image requests, or new animation work were added.

Validation: storefront typecheck, 178 storefront tests, production storefront build, native asset preparation, root lint, Android debug build, and iOS simulator/device SDK builds.
