# CozyCraft Mobile 1.0.46

Removed the full-page home opacity animation from the sofa handoff so the prepared home does not create an extra compositing layer or a final-frame rasterization hitch. The final route swap now opts into React Router's View Transitions API when the WebView supports it, with a short CSS cross-fade and the existing graceful fallback on older devices.

The one-cycle launch timing is unchanged: five seconds of sofa drawing, a one-second finished pose, and an 800ms sofa exit before the prepared home is revealed.
