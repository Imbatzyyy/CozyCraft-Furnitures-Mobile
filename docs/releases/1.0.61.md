# CozyCraft Mobile 1.0.61

- Category price filters now range from zero to PHP 200,000 for Living Room, Bedroom and Dining. Both reset buttons restore the full range; search behavior is unchanged.
- Review photo viewer contains tall images inside a scrollable stage, keeping close, zoom and previous/next controls visible in portrait and landscape.
- Centered vector close icon, 100–300% zoom buttons, double-click/tap zoom toggle and native touch scrolling for enlarged photos. Switching photos resets zoom.
- Lightweight rendering with asynchronous image decoding, isolated image layout, no continuous animation loop, accessible controls and modal focus restoration.

Validation: 215 app tests, TypeScript checks, 16 Chromium/WebKit viewer layout/zoom checks including narrow screens, landscape and enlarged text; 24 price-range responsive checks; Android build and iOS simulator build succeeded. Real low-end/high-end phones and native touch gestures were not benchmarked; this is not a claim of universal device performance.

Direct-install Android debug APK; iPhone source is ready for Xcode, not an App Store/TestFlight release. No website or database changes.
