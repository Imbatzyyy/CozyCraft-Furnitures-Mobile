# CozyCraft Mobile 1.0.53

The chat welcome screen now displays the supplied CozyCraft Care logo in a warm, lightly outlined frame. The original transparent artwork is bundled locally and framed through CSS without distortion. The logo remains visible on narrow and landscape screens, with scrolling available when needed. Conversation and account logic are unchanged.

Android is a direct-install debug APK. iOS source and bundled assets are available for Xcode installation; no App Store or TestFlight submission is included.
