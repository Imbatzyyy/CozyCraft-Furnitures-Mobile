# CozyCraft Mobile 1.0.33

- Limits the floating CozyCraft Care launcher to the main browsing tabs.
- Removes the launcher from product detail, search, comparison, category, profile, notifications, membership, account, checkout, payment return, order confirmation, review, return, and cancellation surfaces.
- Adds a CSS fallback that hides the control during overlay transitions so it cannot flash above a task-focused page.
- Keeps the launcher functional on Home, Shop, Saved, and Bag, with its existing liquid-glass circle, outlined chat icon, green status dot, safe-area spacing, and 56px touch target.

Validation: storefront typecheck, 178 storefront tests, production storefront build, root lint, native asset preparation, Android debug build, and iOS simulator/device SDK builds.
