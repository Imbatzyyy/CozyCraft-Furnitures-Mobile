# CozyCraft Mobile 1.0.71

Fixes Google account setup losing edited names and returning from username setup to Step 1 when the onboarding surface is remounted.

- Retains the same account's active onboarding surface during temporary missing account snapshots, preserving focus and the submission lock.
- Restores edited first/last names, username, and the current step across an ancestor remount. The draft is memory-only, not browser storage; it is cleared on logout, successful setup, or account replacement.
- Account identity changes reset the form. Security checks, database username validation, and voucher issuance remain server-controlled and unchanged.
- Keeps the existing setup → tutorial → welcome voucher sequence, including Skip.

Validation:

- New missing-snapshot and ancestor-remount regressions fail against the previous components and pass with this fix.
- Storefront TypeScript check and 244 tests; 13 native-shell tests.
- Chrome and WebKit at 320px and 390px with extra-large text: edited names, five repeated remounts, keyboard-sized viewport changes, deliberate Back navigation, username completion, tutorial, and voucher.
- Chrome and WebKit: both Finish and Skip hand off to one voucher dialog and restore storefront interaction after dismissal.
- Android debug APK and iOS simulator build validated before publication.
- Live Supabase read-only check: project healthy; all three onboarding/voucher RPCs exist, allow authenticated callers, and deny anonymous callers. No customer records changed for testing.

Distribution: Android direct-install debug APK plus updated iOS source (version 1.0.71, build 59). Not an App Store or TestFlight release. No backend migration and no website deployment. Browser tests use mocked account services; a fresh live Google signup and physical-device keyboard behavior still require device verification.
