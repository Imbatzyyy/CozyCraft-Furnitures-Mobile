# CozyCraft Mobile 1.0.45

The sofa-to-home handoff now uses a coordinated reveal: the sofa surface fades away to expose the already prepared home underneath, while the home surface settles into place with a subtle synchronized reveal. The handoff home also skips its normal page-entry opacity animation, removing the small second fade that could be felt after the transition.

The launch timing remains one five-second sofa drawing cycle, a one-second finished-pose hold, and an 800ms exit transition. The exit callback is kept current through React rerenders so the reveal cannot be lost or delayed.
