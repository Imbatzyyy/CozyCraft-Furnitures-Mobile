# CozyCraft Mobile 1.0.72

Comprehensive onboarding stability fix for manual signup, Google name/username setup, tutorial navigation, and welcome-voucher handoff.

## Main fixes

- Fixed duplicate sibling component keys in the actual storefront that caused two independent Google onboarding forms to appear. A regression check reproduced the issue by restoring only the old keys.
- Process native Google/auth callbacks once, acknowledge delivery, and stop shell retries. Handle callback failures without redirecting an already signed-in shop session because of an old stored callback.
- Reject stale session startup responses and avoid reloading catalog/cart/orders/profile on routine same-account auth metadata updates.
- Keep manual signup steps stable while account requirements load or refresh. Guard rapid taps, held Enter, and duplicate email-resend attempts.
- Preserve non-secret signup fields and the current step through Terms/Back; passwords and consent intentionally reset after leaving the form.
- Keep Google setup locked during a pending save across remounts, preserving edited names and usernames.
- Preserve tutorial progress through remounts; keep Finish/Skip, single spotlight, voucher handoff, focus restoration, and storefront interactivity stable.
- Reduce competing focus/layout work, stacked animations, keyboard-sensitive mascot movement, and large image decoding costs. Responsive WebP mascot assets preserve the original artwork as fallback.
- Distinguish account-settings loading from a real failure and retain entered details on retry.

## Validation

- TypeScript passed; 255 storefront tests across 53 files; 14 native-shell tests.
- Full actual application/router/client audits in Chromium and WebKit, with backend HTTP/WebSocket requests intercepted: manual signup, Google profile completion, tutorial, voucher, and restored storefront interaction.
- Delayed responses, repeated auth metadata updates, one-save assertions, Terms/Back, and keyboard-sized viewport changes.
- 320/390px phones, landscape and tablet layouts, enlarged text, reduced motion, and 25-click tutorial bursts. Chromium CPU throttling at 4x and 6x.
- Android debug APK and iOS simulator compilation. Native assets synchronized from this repository's storefront.
- No database migration or customer record changes. The customer website is unchanged.

## Install and test

Android: install the attached `app-debug.apk`, version **1.0.72**, versionCode **73**, over the previous CozyCraft test build. Keep the existing app data; uninstalling is not necessary for a normally signed upgrade. This is a direct-install debug build, not a Play Store release.

iPhone: the iOS Xcode project is updated to **1.0.72 / build 60**. Install it on the device using Xcode and your configured development signing. The GitHub APK is Android-only. This is not an App Store/TestFlight release, and there is no configured over-the-air channel that updates an already installed iPhone app.

Device acceptance checklist:

1. Fresh manual account: names → username → email → password → real email verification → tutorial.
2. Fresh Google account: edit both names → username → complete setup; verify names and username persist.
3. Tap Next rapidly, open/close the keyboard, background/resume the app, and verify no duplicate forms or step resets.
4. Complete or skip the tutorial on separate eligible accounts; confirm one eligible welcome voucher, dismiss it, and confirm the storefront responds normally.
5. Relaunch the app: completed setup/tutorial should not repeat.

Browser tests use intercepted services; they do not certify live Google authorization, actual inbox delivery, or physical-device smoothness. A fresh account is needed to test first-time flows; a previously completed account should not be expected to receive a second welcome voucher.
