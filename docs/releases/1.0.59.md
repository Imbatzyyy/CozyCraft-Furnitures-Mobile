# CozyCraft Mobile 1.0.59

Added Request an invoice to delivered-order details. The exact order's saved item prices, delivery fee, discount, payment status, and total are sent as a branded ivory-and-olive invoice email to the customer's verified account email.

The popup appears only after the email provider accepts the request. Errors allow retry; duplicate requests share a provider idempotency key. The authenticated backend verifies order ownership and delivered status, and rejects inconsistent amounts. The request-order-invoice endpoint is deployed with JWT verification enabled. No existing database tables or customer website code were changed.

Validation: 210 app tests, backend authorization/ownership/provider-error tests, TypeScript/Deno checks, responsive Chromium/WebKit email and popup layouts, Android and iOS simulator builds. Actual inbox delivery requires a signed-in delivered-order test and is not yet verified.

The invoice is an HTML email with a plain-text alternative: a customer order copy, not a PDF attachment or registered tax invoice. Android is a direct-install debug APK. iPhone source and assets are ready for Xcode installation; this is not an App Store or TestFlight publication.
