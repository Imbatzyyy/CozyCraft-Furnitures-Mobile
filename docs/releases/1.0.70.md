# CozyCraft Mobile 1.0.70

Protects tutorial navigation against rapid repeated input with a synchronous 280ms transition guard and disabled Back/Next controls during movement. Finish is idempotent; duplicate replay requests while replaying are ignored. Skip remains available.

While the tutorial is visible, the iOS navigation glass lens and refraction filters are disabled to prevent the highlighted real button from appearing doubled. The original navigation buttons remain in place; no button clones are created. Normal navigation styling returns when the tutorial closes.

Validation includes repeated 25-click bursts in Chromium and WebKit with normal/reduced motion, a single spotlight, five original navigation targets, hidden glass lens during the tour, cleanup afterward, plus signup/tutorial/voucher regression tests and native builds. Physical-iPhone appearance remains a device verification boundary.

Android direct-install debug APK 1.0.70/code 71. iOS Xcode source 1.0.70/build 58. Not an App Store or TestFlight publication. No backend, reward, search, checkout or website changes.
