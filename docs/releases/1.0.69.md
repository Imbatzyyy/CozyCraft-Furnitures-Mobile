# CozyCraft Mobile 1.0.69

Audits and hardens guided account creation, the welcome tutorial, and the subsequent eligible voucher popup.

Includes the transparent navigation spotlight: the real highlighted button is no longer darkened, with a warm outline and short transitions. Resize/scroll measurements are coalesced into animation frames; reduced-motion and economy modes disable highlight movement.

Fixes voucher actions retaining busy/error state when reopened and protects against duplicate action submissions. Tutorial replay now owns the modal sequence, preventing a waiting voucher from overlapping it when account preferences refresh. Existing Google draft and stale-response protections remain intact.

Checks cover signup validation, password mismatch, duplicate accounts, failed signup, Google name/username steps, tutorial Finish and Skip, voucher handoff/artwork/dismissal, replay, reconnect, and local completion persistence. Chromium and WebKit checks include small screens, landscape, extra-large text, reduced motion, and simulated CPU slowdown. Android and iOS simulator builds are validated. Real Google authorization, email inbox delivery, live reward issuance, and every physical phone are not proven by controlled fixtures.

No database schema or reward-rule change; no new vouchers issued by this audit. Android direct-install debug APK 1.0.69/code 70. iOS Xcode source 1.0.69/build 57, not App Store or TestFlight publication. Website, search and checkout unchanged.
