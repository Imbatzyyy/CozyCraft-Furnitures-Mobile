# CozyCraft Mobile 1.0.30

Native pull-to-refresh for live customer pages.

- Adds a shared pull-to-refresh gesture that works from the top of the active vertical scroll surface on iPhone and Android.
- Shows a compact premium refresh indicator with an armed “Release to refresh” state and a bounded loading spinner.
- Refreshes the visible catalog, settings, delivery areas, homepage content, search suggestions, saved pieces, bag, account records, orders, notifications, Home Circle data, reviews, addresses, profile preferences, and Care & Support FAQ as applicable to the open page.
- Keeps checkout, payment confirmation, search input, chatbot, comparison, and category flows protected from accidental refresh interruptions.
- Uses bounded 12-second requests, offline messaging, cached content, and existing realtime channels so refreshes remain responsive without an unbounded egress burst.
- Preserves the current scroll position and does not reload the entire app or website.

Validation: storefront type check, 178 storefront tests, production storefront build, root Angular lint, native web asset preparation, and iOS/Android native builds passed. The pull gesture has dedicated jsdom coverage for nested scroll-surface detection, bounded drag distance, release threshold, loading state, and reset behavior.
