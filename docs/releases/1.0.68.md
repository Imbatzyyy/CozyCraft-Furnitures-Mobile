# CozyCraft Mobile 1.0.68

Fixes Google name/username onboarding refresh races. Incoming status refreshes no longer overwrite the username draft, clear a running submission lock, or reset the name step. A synchronous submission guard prevents duplicate saves. Stale incomplete-onboarding responses cannot reopen setup after username completion for the same signed-in account.

The nonessential tour-preference update now occurs after username completion, not before it. Cache/preference refresh failures do not turn a successfully committed username into an apparent failed signup. The tutorial then eligible welcome-voucher flow remains intact; reward rules and database schema are unchanged.

Validation includes TypeScript, storefront and native-shell tests, new stale-response/draft/submission-lock regression tests, and the combined Google name → username → tutorial Finish/Skip → sticker voucher flow in Chromium and WebKit. Android and iOS simulator builds verified. Controlled fixtures do not prove live Google-provider authorization or every physical-device behavior.

Android direct-install debug APK: version 1.0.68/code 69. iOS Xcode source: 1.0.68/build 56. Not an App Store or TestFlight release.
