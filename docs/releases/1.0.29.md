# CozyCraft Mobile 1.0.29

Platform-consistent product favorites.

- Replaces the product-detail header's Unicode heart with the same inline vector artwork used by product cards.
- Keeps the outlined and saved states monochrome and crisp in iOS WKWebView instead of allowing Apple emoji substitution.
- Preserves the existing save action and exposes the current state through `aria-pressed` and an updated accessible label.
- Scales the artwork with the responsive header while keeping the control centered and touch-friendly on narrow iPhone and Android layouts.
- Does not change product, cart, account, or network behavior.

Validation: storefront type check, 175 storefront tests, storefront production build, iPhone and Android product-detail fixture DOM/screenshot checks, native web asset preparation, and root Angular lint passed. Native iOS and Android builds are run as part of the release verification.
