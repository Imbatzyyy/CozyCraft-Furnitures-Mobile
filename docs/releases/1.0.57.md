# CozyCraft Mobile 1.0.57

- Notification count text and its badge now scale with all four text-size preferences, including two-digit counts.
- Fixed the support page floating Back button scrolling out of its bottom-left position by removing unnecessary account-sheet backdrop filtering.
- Protected the Back button's rounded appearance and readable text from page-level button styles.

Validation: 206 tests, TypeScript, app build, 24 Chromium/WebKit badge and support layout cases across four text sizes and three widths, plus eight existing floating-Back regression cases. Physical-device safe-area and keyboard checks remain separate.

Android is a direct-install debug APK. iOS source and assets are ready for Xcode installation, not App Store or TestFlight distribution. The customer website was not changed.
