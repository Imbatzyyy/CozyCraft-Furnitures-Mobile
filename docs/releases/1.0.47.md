# CozyCraft Mobile 1.0.47

The signed-in launch now enters the home route before drawing the sofa. The prepared storefront stays mounted while the overlay fades and is removed, preserving loaded data, subscriptions, dialogs, and controls. Completion only clears the one-shot route state; it no longer swaps in a second home or starts another browser view transition.

Home controls remain inert during launch and become available when the overlay is removed. The home layout stays in normal flow throughout. The five-second drawing, one-second hold, and 800ms exit remain unchanged. A regression test checks that the actual home DOM node survives completion, no extra mount or unmount occurs, and its button works afterwards.
