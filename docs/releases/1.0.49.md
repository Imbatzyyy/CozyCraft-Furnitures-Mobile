# CozyCraft Mobile 1.0.49

The My Profile Home Circle card now uses a readable points hierarchy, an outlined tier badge, subtle circular background detailing, and a deep-olive rewards row. Isolated styles prevent older profile-button rules from shrinking or fragmenting the card. All text-size preferences are supported, with wrapping controls on smaller screens.

Recent Activity shows five entries per page with Previous/Next controls and a page indicator. Pagination uses the existing recent-activity feed without extra requests when changing pages. Balances, reward rules, and database records are unchanged. The previously deployed Cozy Nest tier migration remains in place; this release needs no new migration.

The Android attachment is a debug APK for direct installation, not a Play Store release. iOS source and bundled assets are updated for building through Xcode; this is not an App Store or TestFlight publication. The customer website is unchanged.
