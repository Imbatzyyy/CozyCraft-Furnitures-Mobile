# CozyCraft Mobile 1.0.62

## Performance and reliability

- Pause decorative carousel and display-clock intervals while hidden; resume with one fresh interval, without replaying missed ticks. Reward expiry labels refresh on return. Security and payment timers remain unchanged.
- Stop automatic carousel advancement when reduced motion is requested; preserve manual navigation and the established sofa launch sequence.
- React to Data Saver changes without restarting. Resource-constrained devices use simpler pinned-surface glass rendering; devices without resource constraints keep standard effects. Unknown capability hints retain standard behavior rather than guessing device quality.
- Reuse product-image background classifications in a bounded 200-entry cache, avoiding repeated canvas reads when returning to products. No image or canvas buffers are retained. Reset classification when a card's image changes.
- Defer additional off-screen category/order images and request asynchronous decoding. Skip periodic banner polling while hidden/offline; realtime updates remain enabled.

## Verification

- TypeScript and 220 automated tests passed.
- 320 responsive fixture layouts passed using iOS/Android styling, four screen sizes and four text sizes, with photo-navigation, focus, payment-code and keyboard-height checks.
- 21 narrow-screen fixture checks passed in Chromium normal/6x CPU slowdown and WebKit. These test errors/layout, not FPS or real hardware speed.
- Motion checks passed at 320, 390 and 768 pixels, including reduced motion, economy mode and transition transform cleanup.
- Android APK and iOS simulator builds passed.

No claim of universal phone performance or a bug-free app: physical low/high-end devices, thermal conditions, native gestures, live checkout and inbox delivery were not benchmarked/retested in this pass. No website, search rules or database schema changes. Android is a direct-install debug APK; iPhone is Xcode-ready, not an App Store/TestFlight release.
