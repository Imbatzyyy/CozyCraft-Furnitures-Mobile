# CozyCraft Mobile 1.0.83 — Native security and release readiness

October 15, 2026. Android versionCode **84**; iOS build **71**.

## What changed

- Upgrade Capacitor core, CLI, Android, iOS and the resolved Swift package to
  **8.5.1**, addressing GHSA-rvm3-566m-v7fv. This requires installing a rebuilt
  native app; a website update alone cannot patch an existing installation.
- Update compatible Angular build tooling, Vite, Vitest and available
  nonbreaking transitive dependencies. Runtime dependency audits now gate the
  mobile release checks.
- Prevent empty product-image URLs from making an unintended document request.
- Isolate the mock QA entry's Vite dependency cache from the real app's cache.
- Add repeatable Chromium/WebKit readiness checks covering signup, tutorials,
  welcome vouchers, recovery, cart/wishlist state, menu navigation and layouts.
- Include the reviewed Xcode dependency-recovery improvements: the launcher
  checks every local Swift plugin manifest and restores locked npm dependencies
  when necessary before resolving CapApp-SPM. Preserve the Xcode 27 upgrade
  metadata and the existing **iOS 16.0** minimum instead of an automatically
  changing recommended deployment target.

## Verification

- Release verification passed: **378 storefront tests**, **25 shell tests**,
  **11 Xcode-toolchain tests**, TypeScript, lint and shared-backend ownership.
- **56 browser scenarios** passed using pinned Playwright 1.64.1 and its
  Chromium/WebKit engines: 14 full-app onboarding/voucher journeys, 4 bounded
  read/recovery cases, 18 reliability cases and 20 navigation/layout combinations.
  The suites intercept backend traffic and do not create real accounts/orders.
- Xcode **27.0** builds passed for both iOS Simulator and generic physical-device
  architectures, with signing disabled for these verification builds. The app
  installed and launched in the iOS 27 iPhone 17 QA simulator. The correct

- Android debug APK built with Java 21. The manifest reports 1.0.83 / 84, and its
  signature verifies and matches the prior 1.0.82 debug release certificate.
- **159 web files** match the prepared bundle, Android/iOS assets, the built
  iOS Simulator app and the Android APK.
- Production dependency audits report **zero known findings** for the mobile
  shell and storefront. The storefront's complete audit is also clean.

## Release boundaries

- This APK is **debug-signed for testing**, not a Play Store submission. There
  is no App Store/TestFlight upload or physical-phone installation. Installation
  on Prince iPhone 17 remains with the user through Xcode.
- Simulator and browser fixtures do not prove physical-device performance,
  real Google/payment-provider round trips, inbox delivery or remote push.
  Apple remote push still needs APNs credentials; existing in-app/local
  notification behavior is separate.
- Xcode reports a nonblocking optional-to-Any warning in the upstream
  `@capacitor/app` plugin and an unused App Intents metadata warning. Neither
  blocks either native build; no vendor source was patched locally.
- The mobile shell's full development dependency audit retains **16 entries
  (12 high, 4 moderate)** through braces/Karma/Webpack and uuid/Xcode tooling.
  Forced audit suggestions introduce incompatible changes; keep development
  servers local and track upstream fixes. Do not call all tooling clean.
